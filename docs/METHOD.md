# Maintained architecture: v3

Numeric actions contain six dietary factors (carbs, protein, fat, fiber, mass in grams; energy in kcal), three exercise factors (minutes, kcal, source-native intensity), masks, and onset defined as origin minus action start in minutes. Future actions have negative onset. Unknown intensity stays masked; candidate named-scale intensity is retained in audit output and masked from numeric models whose training scale is undefined.

A shared state encoder combines valid-weighted CGM patches, recent patch, aligned Qwen3 semantic metadata features, last CGM and observation gap. Domain-specific conditioning, time-shared basis matrices and residual dynamics produce future states. Causal trajectory Transformers and physiological readouts are domain-specific. Fusion starts with block-diagonal bases and three independently sigmoid-gated increments. A shared ranking head reads trajectories independently from physiological prediction and produces unbounded internal logits. Public inference returns prescription order without numerical ranking values.

Single-domain training learns action/state encoders and domain branches. Fusion freezes action/state encoders and domain dynamics/readouts while training conditioners and fusion components. The shared physiological_loss in train.py serves training and controlled experiments. No true future values enter rollout.

Professional then physiological alignment uses standard DPO on a candidate-selection policy pi(a|x)=softmax(u(x,a)), where u is the internal ranking logit. The objective is weighted negative logsigmoid of beta times the preferred/rejected policy log-probability-ratio difference against a frozen prior-stage reference. The common policy normalizer cancels between each preference pair, so pairwise log-softmax gives the same loss and gradients as normalization over the full candidate set. Replay defaults to 25%. No CGM loss is added during DPO. Only ranking parameters update. Physiological preferences require independently sourced factual observation IDs. No fabricated counterfactual curves are accepted as evidence. User feedback training is not implemented.

Checkpoints record architecture, action backend, normalizers, trained domains/ranked modes, splits, phase, optimizer and random state. Metadata fields and vector width are inferred through the dataset interface and lazy alignment layer. Former numeric-metadata checkpoints require retraining; see METADATA.md. The paper action path uses separately full-parameter-fine-tuned Qwen2.5-VL encoders, mean-pooled input hidden states and supervised physiological factor heads. Remote VLMs and factor heads are frozen during world-model training; local joint explicit/latent projections learn during single-domain training and freeze thereafter. HTTP factor extraction requires matching artifact identity and retraining from old latent checkpoints. Action factor widths, names, units and scales are supplied by HTTP factor_schema; independent mean-pooled latent effectors are concatenated with normalized explicit factors. Full 72B model verification has been completed by the project team. Former factor-only HTTP checkpoints require retraining.

Controlled variants: patch_size, state_pooling=both|pooled|recent, gap_feature=true|false, readout=direct|autoregressive. The retained autoregressive numerical decoder uses free rollout. Defaults preserve previous numerical behavior. Change one factor on fixed seeds/data/epochs before attributing improvements. No improvement is assumed.

Persistence and least-squares linear extrapolation read observed history only. DLinear independently implements moving-average trend/residual linear prediction; optional numeric action correction is labelled separately. No external code was copied. Controlled experiments currently train single-domain world models; joint report counts are zero. Evaluate trained fusion artifacts through train.py --predict-only --mode joint. RevIN, TCN, self-supervision and multivariate sensor fusion remain optional future experiments.

Five-seed participant80/unseen20 experiments reserve a purged late holdout within seen participants. Statistics use training records only. Report zero-shot unseen separately from optional factual participant fine-tuning, per mode/history missingness, horizon, MAE/mean per-curve Pearson, elapsed time and peak allocated CUDA memory. Local smoke results do not establish generalization.

CBG/night task adapters validate explicit measured points, units, label provenance and task windows on a 5-minute grid. Night requires recorded bedtime/wake anchors. Task-specific action semantics and training remain prerequisites; event-CGM experiments do not establish overnight capability.

Ranking checkpoints use ranking_version=2. Previous unaligned single/fusion checkpoints may initialize the new path; previous bounded-ranking professional/physiological checkpoints must restart alignment from fusion. Public recommendations use schema_version=2 and expose order rather than scores.
